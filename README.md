# Bader Wandstudio

Visualisierungs-Tool für Maler: Wand fotografieren (oder Standardwand nehmen), Grundton und Putzeffekt wählen und Schablonen darüberlegen.

## Funktionen
- Standardwand (4,00 × 2,20 m) oder eigenes Foto, Wandecken anpassbar
- Grundton: Glatt, Kalkputz, Marmorino, Metallic, Beton-Optik
- NCS-Farbkarte (Bildschirm-Annäherung, verbindlich bleibt der Farbfächer)
- Schablonen als Einzelmotiv, Bordüre oder ganze Fläche, eigene Schablonen per Foto
- Spachteln: unregelmässig, Ränder betont, Teile wegnehmen/zurückholen
- Inseln mit ausgebrochenem Rand, eigener Grund-Deckkraft und Lasur
- Zoomen mit zwei Fingern, Schritt zurück, Bild speichern

## Online stellen (GitHub Pages)
1. Alle Dateien **inklusive Ordner `stencils`** in ein GitHub-Repository hochladen.
2. Settings → Pages → Branch `main`, Ordner `/ (root)` → Save.
3. Nach 1–2 Minuten läuft das Tool unter `https://<benutzername>.github.io/<repo-name>/`.
4. Auf dem Handy die Seite öffnen und „Zum Home-Bildschirm“ wählen – dann erscheint das Logo als App-Symbol.

## Hinweis
Die Schablonen-Vorlagen stammen aus den Katalogen von Novacolor (19) und Decorama (384, Ordner `stencils/`). Vor einer öffentlichen oder kommerziellen Nutzung die Erlaubnis des Herstellers einholen oder die Muster entfernen.
